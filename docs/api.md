# FinBridge REST API

Generated by `scripts/api_reference.py` from the running backend's OpenAPI document (application version 0.7.0, 42 operations). The machine-readable document is `docs/reference/openapi.json`; with the `dev` profile it is also served at `/v3/api-docs`, with Swagger UI at `/swagger-ui.html`.

## Conventions

- Base path `/api`. JSON only. Every endpoint except login needs `Authorization: Bearer <token>`.
- Roles: **A** = ADMIN, **F** = FINANCE_MANAGER, **O** = INTEGRATION_OPERATOR. A wrong role gets `403 ACCESS_DENIED`; no or an invalid token gets `401 UNAUTHENTICATED`.
- Success: `{ "data": ..., "meta": { "page", "size", "totalElements", "totalPages" }, "correlationId", "timestamp" }`. `meta` is present on lists. Fields that are null are left out.
- Error: `{ "error": { "code", "message", "fieldErrors": [ { "field", "message" } ] }, "correlationId", "timestamp" }`.
- Lists take `page` (from 0), `size` (1 to 100, default 20) and `sort=field,asc|desc`. Only the fields named for each list are accepted.
- Dates are `yyyy-MM-dd`; instants are ISO 8601 in UTC (`2026-11-13T09:30:00Z`).
- Every response carries `X-Correlation-Id`. Send your own UUID in that header and it is used.

| Status | Meaning |
| --- | --- |
| 200, 201, 204 | Done |
| 202 | Accepted; a run was started in the background. Poll it |
| 400 | The request is malformed or a value is invalid (`fieldErrors` says which) |
| 401 | No valid token, or the session was ended |
| 403 | The role is not allowed |
| 404 | No such record |
| 409 | Conflicts with the current state (a duplicate, a run in progress, a concurrent change) |
| 422 | Well formed, but a business rule forbids it |
| 502, 504 | An external system failed or timed out, and nothing was changed |
| 503 | The database is unavailable |
